# O nome: Eufrosine

## Quem é

Eufrosine é uma das três Cárites, as Graças, filhas de Zeus e da oceânide Eurínome, segundo
Hesíodo. Cada uma guarda uma face da alegria: Aglaia, o esplendor; Tália, o florescimento e a festa;
Eufrosine, o bom ânimo, a alegria que se sente quando se está entre os seus. O nome vem de
*euphrosýnē*, alegria.

As Graças presidiam os banquetes, as danças e as celebrações. Eram convidadas das festas dos deuses
e, entre os mortais, a sua presença era o que fazia de uma reunião uma festa de verdade.

## Por que este projeto

Eufrosine é um site de aniversário: a contagem regressiva, a confirmação de quem vem e a lista de
presentes que some conforme os convidados escolhem. É a parte prática de reunir as pessoas, feita
para que sobre espaço para o que a Graça representa: a alegria de estar entre os seus no dia da
festa.
